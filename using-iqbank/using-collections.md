# Using Collections

To open the course’s Collections page, use either of the following options:

- Select **Browse Collection** on the course homepage.
- Select **Collections** in the website header.

In the collection page, you can see all collections available for the course. 

Use the **Filter** button to filter collections by term (Fall, Winter, or Summer), type (Term test, Quiz, Midterm, Final, Other), or by year.

![Viewing collection with filter]({{ "/assets/images/using-iqbank/viewing-collection-with-filter.png" | relative_url }})
{: .guide-image .guide-image--medium }

*Filtering UofT's CSC369 collections to show those that were created in 2019.*
{: .guide-caption }

Select a collection to view its individual questions. While viewing a question you can:

- Select **Question List** to open a list of all collection questions.
- Use the **arrow buttons** in the header to move to the previous or next question.
- Select **Download** to download the entire collection as a PDF.
