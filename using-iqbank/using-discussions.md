# Using Discussions

IQBank provides two types of discussion areas:

- **Collection discussions** is intended for you to discuss the content and possible solutions of individual collection questions.

- **General Discussions** is intended for you to engage in course-wide conversations that are not associated with a particular collection question (eg: Discussing course topics, study advice, etc).

## Opening a Discussion Area

### Collection Discussions

Open a collection question (see [Using Collections]({{ "/using-iqbank/using-collections.html" | relative_url }})) and select the **Discussion** tab to view conversations associated with that question.

### General Discussions

To open a course’s **General Discussions** page, use either of the following options:

- Select the **Discussions** button displayed for courses on the **Explore Courses** page.
- Select **General Discussions** in the course header.

## Creating Discussions, Threads, and Replies

In the discussion areas, you can either start a new conversation or contribute to an existing one by creating discussions, threads or replies.

There are 2 available posting options:

- **Post anonymously to classmates:** This option hides the author's identity from other students, while their identity remains visible to course instructors.

- **Contains a potential answer:** This option hides thread content behind a spoiler block until the viewer chooses to reveal it.

Depending on whether either or both options are available during post creation, these options can be selected separately or together. The following example shows a collection discussion created with both options.

## Browsing Conversations

When browsing threads in either discussion area, you can:

- Sort threads by **Most Likes**, **Most Recent**, or **Oldest**.
- Like useful posts to help increase their visibility to other students and instructors.
