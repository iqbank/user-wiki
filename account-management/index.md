## Navigate to profile page

You can manage your account settings through the Profile page. To access your profile, press the Gear icon on the website header, then select **View Profile**.

![Navigation to profile page]({{ "/assets/images/account-management/nav-to-profile.png" | relative_url }})
{: .guide-image .guide-image--medium }

## Updating your profile picture
Use the **Update Avatar** panel to upload a new profile picture. Remember to choose a school-appropriate image that contains no offensive or harmful content.

{: .warning }
Images must not exceed **5 MB** in size. 

![Update profile picture]({{ "/assets/images/account-management/update-profile-picture.png" | relative_url }})
{: .guide-image .guide-image--medium }

## Manage visibility settings
IQBank supports both light and dark display modes. By default, the display mode will be set to match your device’s system preferences. However, you can override the display mode by clicking on the Gear icon on the website header and pressing the **Light/Dark mode** toggle.

![Manage page visbility]({{ "/assets/images/account-management/manage-visibility-settings.png" | relative_url }})
{: .guide-image .guide-image--medium }

## Change/Reset password
You can change or reset your password by clicking on the Gear icon on the website header and pressing the **Change Password** toggle. After then, please follow the on screen instructions. Once completed, please log out of your current session and re-login using your new password.

![Change password toggle]({{ "/assets/images/account-management/change-password-toggle.png" | relative_url }})
{: .guide-image .guide-image--medium }
