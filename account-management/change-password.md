# Change Password
You can change your account password by clicking on the **Gear icon** on the website header and click the **Change Password** toggle. After then, please follow the on screen instructions. Once completed, please log out of your current session and re-login using your new password.

![Change password toggle]({{ "/assets/images/account-management/change-password-toggle.png" | relative_url }})
{: .guide-image .guide-image--medium }

*Select **Change Password** from the account settings dropdown menu.*
{: .guide-caption }

![Manage page visbility]({{ "/assets/images/account-management/change-password-success.png" | relative_url }})
{: .guide-image .guide-image--medium }

*Enter your current password and a new password that meets the on-screen listed requirements. Success message will be displayed when process completed.*
{: .guide-caption }
