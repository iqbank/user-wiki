# Manage Course Topics

{: .note-title }
> Note:
>
> This feature is available to course instructors and TAs.

To find the **Course Info** page, please see [Using Course Info]({{ "/using-iqbank/course-info.html" | relative_url }}).

On that page, a pencil icon will appears beside the Course Topics heading. Click it to enter edit mode, where you can:

- **Add a topic**: Use the **+ Add a new topic** button that appears at the bottom of the panel while in edit mode. Then, input a topic name (name must be between **2 and 50 characters**) and a colour.

- **Delete a topic**: Delete a topic using the **(x) icon** next to the tag. IQBank will ask to confirm deletion.

- **Rename a topic**: Click on the topic name and type in a new one. Topic names must adhere to the same length limit as in **Add a topic**. IQBank will ask to confirm renames.

Click the **checkmark icon** to finish editing.
