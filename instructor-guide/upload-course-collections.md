# Upload New Course Collection

{: .note-title }
> Note:
>
> This feature is only available to course instructors.

## Upload collection

Create a new course collection by uploading a PDF file, then fill out the required **Title**, **Type**, **Year**, and **Term** fields. 

Max file size: **5 MB**.

![Upload Collection]({{ "/assets/images/instructor-guide/upload-collection.png" | relative_url }})
{: .guide-image .guide-image--medium }

*Upload collection PDF*
{: .guide-caption }

## Create Questions

After uploading the PDF and entering the collection details, press the **Continue to Create Questions** button.

The uploaded PDF would then appears on the left, while the **Question List** appears on the right. Use this page to indicate the questions and subquestions contained in the PDF.

1. In the **Question List** panel, select **Add Question** under **Actions**. Use the browser cursor to select the area of the PDF containing the question. When finished, select **Finish**.

    Optionally, assign one or more topic tags to categorize the question.

    ![Before adding Question 1 to the new collection]({{ "/assets/images/instructor-guide/before-add-collection-question.png" | relative_url }})
    {: .guide-image .guide-image--medium }

    ![While adding Question 1 to the new collection]({{ "/assets/images/instructor-guide/during-add-collection-question.png" | relative_url }})
    {: .guide-image .guide-image--medium }

2. If the question contains multiple parts, select the **Add Subquestion**. For each subquestion, repeat step 1.

    ![Adding question 1 subquestion to new collection]({{ "/assets/images/instructor-guide/add-collection-subquestion.png" | relative_url }})
    {: .guide-image .guide-image--medium }

3. Repeat steps 1 and 2 for each remaining question in the PDF.

    Created questions appear in the **Question List**. If necessary, drag and drop the entries to change their order.

    After identifying and ordering all questions, select **Continue to Review**.

    ![Adding more questions to new collection]({{ "/assets/images/instructor-guide/final-add-collection-question.png" | relative_url }})
    {: .guide-image .guide-image--medium }

## Review Creation
Here, the details of the uploaded collection can be reviewed. 

If further edits need to be made, press the **Back to Edit** button. 

Otherwise, press the **Finalize Questions** button to upload the new course collection.

When completed, a success dialog will appear. The new collection would now be displayed in the course's **Collections** page.
